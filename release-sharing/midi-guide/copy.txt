Open MIDI → MIDI Settings in Cosmos. Select the input port and channel for your pedal or controller. Choose a target, click Learn, then press the pedal or turn a knob. Assign ERASE ALL separately.
In Tap mode each press can send just 127. In free recording the first press starts and the next stops. For Hold, send 127 when you press and 0 when you release.
In R / PR programs 1–9, start audio, enable MIDI Clock sync and choose 1, 2 or 4 bars. Start the external clock and transport, then press RECORD. Recording starts on the next bar. Programs 10–12 run freely.
Cosmos presets save your mappings. Enable Program Change to recall populated slots 01–32 with PC 0–31.
Insert Cosmos AU on an audio or return track. Enable Remote for the controller’s input port and unfold the device. Press ⌘M, select RECORD tap and press your pedal. Repeat for ERASE ALL tap. Press ⌘M again and save the Live Set.
For each pedal, send 127 on press and 0 on release, on the same channel and CC. In free mode, press once to record, release to keep recording, then press again to stop. Erase clears only this instance’s loop.
In R / PR programs 1–9, enable Sync to Live bars. Start Live’s transport, then press RECORD to start on the next bar. Live maps directly to the parameter, so no separate MIDI track is needed.
Release the pedal and press again. If Live still waits, check that release actually sends 0 on the same CC as the press. Live stores these mappings in the Set.

ऑडियो या रिटर्न ट्रैक पर Cosmos AU लगाएँ। कंट्रोलर के इनपुट पोर्ट पर Remote चालू करके डिवाइस का तीर खोलें। ⌘M दबाएँ, RECORD टैप चुनें और पैडल दबाएँ। ERASE ALL टैप के लिए दोहराएँ। ⌘M से बाहर निकलें और Live सेट सहेजें।
हर पैडल के लिए उसी चैनल और CC पर दबाने पर 127 और छोड़ने पर 0 भेजें। स्वतंत्र मोड में पहली बार दबाने पर रिकॉर्डिंग शुरू होती है, छोड़ने पर जारी रहती है और अगली बार दबाने पर रुकती है। मिटाने से सिर्फ़ इस प्लगइन का लूप मिटता है।
R / PR के प्रोग्राम 1–9 में Live बार सिंक चालू करें। Live का प्लेबैक शुरू करें, फिर RECORD दबाएँ ताकि अगले बार पर रिकॉर्डिंग शुरू हो। Live सीधे पैरामीटर को नियंत्रित करता है, अलग MIDI ट्रैक की ज़रूरत नहीं।
पैडल छोड़कर फिर दबाएँ। इंतज़ार बना रहे तो जाँचें कि छोड़ने पर उसी CC से 0 भेजा जाता है। ये मैपिंग Live सेट में सहेजी जाती हैं।

Với R / PR 1–9, bật đồng bộ ô nhịp với Live. Bật phát trong Live rồi nhấn RECORD để bắt đầu ở ô nhịp tiếp theo. Live gán trực tiếp vào tham số, không cần thêm track MIDI.
Nhả rồi nhấn lại. Nếu Live vẫn chờ, kiểm tra bàn đạp có gửi 0 trên đúng CC khi nhả không. Các ánh xạ này được lưu trong Live Set.

짧게 누르기는 밟을 때마다 127만 보내도 됩니다. 자유 녹음에서 첫 번째로 밟으면 녹음이 시작되고 다시 밟으면 멈춥니다. 길게 누르기는 밟을 때 127, 뗄 때 0을 보냅니다.

Cosmos 프리셋에 매핑도 저장됩니다. Program Change를 켜면 PC 0~31로 저장된 슬롯 01~32를 불러올 수 있습니다.
